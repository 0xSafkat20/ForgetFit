
# 🏋️ ForgetFit — WordPress Gym & Fitness Theme

ForgetFit is a modern, fully responsive WordPress theme designed for gyms, fitness centers, and personal trainers. It features a bold black-and-yellow design, customizable content, and a user-friendly interface.

## 📸 Project Preview

![ForgetFit Website Preview](./screenshot.png)

## ✨ Features

- Modern, responsive website design
- Customizable homepage and branding
- Training programs and membership sections
- Club showcase and member reviews
- Contact page and free-pass form
- Dedicated FAQ page with reusable membership and first-visit answers
- Five editable beginner-focused blog guides in the Training Guides category
- Companion operations plugin with custom data tables and staff-ready roles
- ForgetFit admin health dashboard and starter membership plans
- Persistent free-pass lead inbox with statuses, staff assignment, notes, filters, and CSV export
- Editable membership plans that update the public pricing cards
- Audit logging for operational changes
- Social media integration
- WordPress Customizer support
- Easy navigation and content management

## 🛠️ Technologies Used

- **WordPress** — Content Management System
- **PHP** — Theme development
- **HTML5 & CSS3** — Structure and styling
- **JavaScript** — Frontend interactions
- **MySQL** — Database
- **XAMPP** — Local development environment

## ⚙️ Installation

1. Download the repository as a ZIP file.
2. Extract the theme folder.
3. Go to **WordPress Dashboard → Appearance → Themes**.
4. Click **Add New → Upload Theme**.
5. Upload the theme ZIP file and activate it.
6. Customize settings through **Appearance → Customize**.

### Operations plugin

The mid-level application features live in `companion-plugin/forgetfit-core` so business data is not tied to the theme. Copy that folder to `wp-content/plugins/forgetfit-core`, activate **ForgetFit Core**, then open **ForgetFit** in the WordPress admin menu. Local development can use a directory junction instead of a copy.

## 📋 Requirements

- WordPress 6.6+
- PHP 7.4+
- MySQL or MariaDB
